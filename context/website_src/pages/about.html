The idea

WHERE filters one row at a time. DECIDE constrains the whole set of decisions at once.

Package queries asked a database for a set of rows that satisfies constraints over the set: a meal plan under a calorie budget, a portfolio within a risk limit. DeciDB generalizes them from choosing rows to deciding numbers (yes or no, whole quantities, continuous amounts), one per row, per key or for the whole query, and from linear rules to quadratic ones, such as a sum of squares or a product of two decisions.

Three scope words say which rows a rule covers: when keeps the rows where a condition holds, per writes one copy of the rule for each group, and by says which rows each sum adds up. They come from the DECIDE language proposal, which DeciDB builds in part; the guide lists what is not built yet.

How it is built

DuckDB
The embeddable analytical engine DeciDB extends: parser, binder, optimizer and execution each own one part of a DECIDE query.
Gurobi
Used when its library and license are present: every model class, and the fastest on these workloads.
HiGHS
Bundled and open source: LP, MILP and convex QP, with no setup.
Query rewriting
Rules that recognize nine problem classes with an exact relational answer and rewrite the query to compute it with relational operators, skipping the solver.
Testing
A Python suite that checks each answer against an independent model solved by Gurobi, and each refusal against its message, run on each solver and with query rewriting on and off.
Distribution
Tagged releases ship command-line binaries for macOS, Linux and Windows, and Python wheels.
