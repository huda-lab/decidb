Install

Three ways in: the command-line shell, the Python package, or a build from source.

Command-line shell

The command-line shell is one self-contained binary. Download the archive for your platform:

PlatformRequirements
Linux x86-64Ubuntu 18.04+, CentOS 7+Download
macOS (universal)macOS 11+Download
Windows x64Windows 10+Download
unzip decidb_cli-osx-universal.zip # or the Linux archive chmod +x decidb ./decidb --version Expand-Archive decidb_cli-windows-amd64.zip -DestinationPath . .\decidb.exe --version
Unsigned binaries

On macOS, right-click the binary, choose Open and confirm. On Windows, choose "More info" and then "Run anyway" in SmartScreen.

Coming from 0.2

Release 1.0 uses the spellings on this site. A query written for 0.2, such as one with PER after a constraint, is a syntax error in 1.0; the guide's migration table gives the new spelling of each.

Python

Wheels are published for Python 3.11 to 3.15 on macOS (Apple Silicon), Linux (x86-64) and Windows (x86-64).

pip install decidb import decidb con = decidb.connect() con.sql("SELECT 42").fetchall()

Gurobi (optional)

Every build solves with HiGHS, which is bundled. DeciDB also uses Gurobi 9.5 to 13 when it finds one, with its license: Gurobi is faster on large models and takes a few that HiGHS cannot (see the guide's solvers). DeciDB finds Gurobi through GUROBI_HOME, the library path, or Gurobi's default install folder.

Build from source

You need a C++17 compiler, CMake 3.15+, Python 3 and Git; Ninja is used when present.

git clone {{GITHUB}}.git cd decidb make release ./build/release/decidb --version

On Windows, with Visual Studio 2019+ and Ninja:

cmake -G Ninja -B build/release -DCMAKE_BUILD_TYPE=Release -DDISABLE_UNITY=1 ninja -C build/release

Your first query

Start the shell. With no file name the database lives in memory; ./decidb shop.db opens or creates a file.

./decidb

Create a small table of items, each with a value and a weight:

CREATE TABLE Items (item VARCHAR, value INT, weight INT, category VARCHAR); INSERT INTO Items VALUES ('Laptop', 100, 20, 'tech'), ('Camera', 60, 10, 'tech'), ('Drone', 120, 30, 'tech'), ('Tripod', 40, 15, 'gear'), ('Lens', 75, 12, 'gear');

Which items should go in a bag that holds 50 kg, to carry the most value?

SELECT item, value, weight, x AS take FROM Items DECIDE x(BOOL) SUCH THAT SUM(x * weight) <= 50 MAXIMIZE SUM(x * value);

The query returns every row, with the decision x filled in: 1 for the laptop, camera and lens, 0 for the rest. Together they weigh 42 kg and are worth 235, and no other choice under 50 kg is worth more.

The guide takes this query apart clause by clause and builds on it.

From Python

In Python, a DECIDE query runs like any other query and returns a relation you can turn into a DataFrame:

import decidb con = decidb.connect() con.sql("CREATE TABLE Items AS SELECT * FROM 'items.csv'") answer = con.sql(""" SELECT item, x FROM Items DECIDE x(BOOL) SUCH THAT SUM(x * weight) <= 50 MAXIMIZE SUM(x * value) """).df()
