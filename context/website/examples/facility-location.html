Which depots to open

Open depots and route shipments so every customer's demand is met, paying a fixed cost for each open depot plus a cost per unit shipped.

MILP

The problem

Three depots can serve four customers along the routes listed in Routes. A depot ships nothing unless it is open, and opening it has a fixed cost. Two decisions with different keys: open is one per depot, ship one per route.

The data

SetupRuns as shown
CREATE TABLE Depots (depotID VARCHAR, region VARCHAR, capacity INT, opening_cost INT);
INSERT INTO Depots VALUES ('D1', 'North', 120, 500), ('D2', 'North', 80, 300), ('D3', 'South', 150, 650);

CREATE TABLE Customers (customerID VARCHAR, demand INT);
INSERT INTO Customers VALUES ('C1', 40), ('C2', 55), ('C3', 30), ('C4', 45);

CREATE TABLE Routes (depotID VARCHAR, customerID VARCHAR, unit_cost DOUBLE);
INSERT INTO Routes VALUES
    ('D1', 'C1', 2), ('D1', 'C2', 4), ('D1', 'C3', 5),
    ('D2', 'C1', 3), ('D2', 'C2', 2), ('D2', 'C4', 6),
    ('D3', 'C2', 5), ('D3', 'C3', 1), ('D3', 'C4', 2);

The query

DECIDE queryRuns as shown
SELECT D.depotID, C.customerID, open, ship
FROM Routes R
JOIN Depots D USING (depotID)
JOIN Customers C USING (customerID)
DECIDE per D: open(BOOL), ship(INT)
SUCH THAT per C: SUM(ship) by (C) >= C.demand
      AND per D: SUM(ship) by (D) <= D.capacity * open
MINIMIZE SUM(R.unit_cost * ship) + SUM(D: D.opening_cost * open);

Problem class: MILP, solved by Gurobi or HiGHS.

How it reads

DECIDE per D: open(BOOL), ship(INT)
Each declarator has its own key: open is one per depot, ship (no key) one per route row.
per C: SUM(ship) by (C) >= C.demand
One constraint per customer: what reaches it covers its demand. A relation name as the key stands for all its columns.
per D: SUM(ship) by (D) <= D.capacity * open
One constraint per depot. A closed depot has capacity 0.
SUM(D: D.opening_cost * open)
The colon form: one term per depot, so each fixed cost counts once even though a depot appears on several routes.

The answer

Open D2 and D3, keep D1 closed. D2 serves C1 and most of C2; D3 serves the rest of C2, all of C3 and C4. D1 has cheap routes to C1, but its 500 opening cost outweighs the savings.
