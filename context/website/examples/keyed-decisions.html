One decision per nurse, not per shift

After a join each nurse appears once per shift, but the decision is about the nurse. A keyed declaration makes one decision per nurse.

ILP

The problem

A ward keeps at most 60 hours of the coming shifts and wants the most skilled team. Joining nurses with shifts gives one row per shift, but a nurse is kept or released as a whole. With a per-row decision the solver could keep Alice on Monday and drop her on Tuesday.

The data

SetupRuns as shown
CREATE TABLE nurses (id INT, name VARCHAR, skill_score INT);
INSERT INTO nurses VALUES (1, 'Alice', 9), (2, 'Bob', 6), (3, 'Carol', 8), (4, 'Dan', 5);

CREATE TABLE shifts (nurse_id INT, shift_date DATE, hours INT);
INSERT INTO shifts VALUES
    (1, '2026-12-01', 12), (1, '2026-12-02', 12), (1, '2026-12-03', 12),
    (2, '2026-12-01', 8), (2, '2026-12-03', 8),
    (3, '2026-12-02', 12), (3, '2026-12-04', 10),
    (4, '2026-12-01', 6), (4, '2026-12-02', 6), (4, '2026-12-04', 6);

The query

DECIDE queryRuns as shown
SELECT n.name, s.shift_date, s.hours, keep
FROM nurses n JOIN shifts s ON n.id = s.nurse_id
DECIDE per n: keep(BOOL)
SUCH THAT SUM(keep * s.hours) <= 60
MAXIMIZE SUM(per n: keep * n.skill_score)
ORDER BY n.name, s.shift_date;

Problem class: ILP, solved by Gurobi or HiGHS.

How it reads

DECIDE per n: keep(BOOL)
One decision per nurse (per distinct row of n), shared by all of that nurse's shift rows. Four decisions, not ten.
SUM(keep * s.hours) <= 60
A sum reads result rows, as SQL does over a join: each shift's hours count once.
SUM(per n: keep * n.skill_score)
A reducer with its own per reads one value per nurse, so a nurse's skill counts once, not once per shift.

The answer

Bob, Carol and Dan: 56 hours and a combined skill of 19. Alice is the most skilled nurse, but her 36 hours leave room for only one other nurse, and no such pair reaches 19.

The colon form

SUM(n: e) is shorthand for SUM(per n: e): one term per tuple of the named relation. This objective is the same as the one above:

SQLRuns as shown
SELECT n.name, keep
FROM nurses n JOIN shifts s ON n.id = s.nurse_id
DECIDE per n: keep(BOOL)
SUCH THAT SUM(keep * s.hours) <= 60
MAXIMIZE SUM(n: keep * n.skill_score);
