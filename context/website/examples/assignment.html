Assign people to tasks

Every task gets exactly one person, nobody gets two tasks, and the total fit score is as high as possible.

ILP

The problem

Each row is a person–task pair with a fit score. There are four people and three tasks. A DECIDE query is a query like any other, so it can sit in a subquery and its answer can be filtered.

The data

SetupRuns as shown
CREATE TABLE Fit (worker VARCHAR, task VARCHAR, score INT);
INSERT INTO Fit VALUES
    ('Ana', 'Backend', 9), ('Ana', 'Frontend', 6), ('Ana', 'Data', 7),
    ('Ben', 'Backend', 8), ('Ben', 'Frontend', 8), ('Ben', 'Data', 4),
    ('Cleo', 'Backend', 7), ('Cleo', 'Frontend', 5), ('Cleo', 'Data', 9),
    ('Dev', 'Backend', 5), ('Dev', 'Frontend', 7), ('Dev', 'Data', 6);

The query

DECIDE queryRuns as shown
SELECT worker, task, score FROM (
    SELECT worker, task, score, assign
    FROM Fit
    DECIDE assign(BOOL)
    SUCH THAT per worker: SUM(assign) by (worker) <= 1
          AND per task: SUM(assign) by (task) = 1
    MAXIMIZE SUM(assign * score)
) WHERE assign = 1
ORDER BY task;
Result3 rows

Problem class: ILP, solved by Gurobi or HiGHS.

How it reads

per worker: ... by (worker) <= 1
One constraint per person: at most one task.
per task: ... by (task) = 1
One constraint per task: exactly one person.
MAXIMIZE SUM(assign * score)
The best total fit.
WHERE assign = 1
The outer query keeps only the chosen pairs.

The answer

Ana takes backend, Cleo data and Ben frontend, for a total score of 26. Dev is left out: his best score, 7, is lower than each chosen pair's.
