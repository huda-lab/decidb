Allocate a budget fairly

Split 100 units among programs so that the worst-served program gets as large a share of its need as possible.

Direct solve: R4_MAX_MIN_FAIRNESSmax-min fairnessMIN in the objectivedirect solve

The problem

Four programs need 110 units in total but only 100 are available, and each program can absorb only so much. Max-min fairness raises every program's share of its need together until the budget runs out. MAXIMIZE MIN(...) says exactly that.

The data

Setup
CREATE TABLE Programs (program VARCHAR, need DOUBLE, max_alloc DOUBLE);
INSERT INTO Programs VALUES
    ('Clinic', 20, 40), ('Shelter', 30, 25), ('School', 50, 60), ('Pantry', 10, 30);

The query

DECIDE query
SELECT program, need, max_alloc,
       ROUND(alloc, 2) AS alloc, ROUND(alloc / need, 3) AS share
FROM Programs
DECIDE alloc(REAL)
SUCH THAT alloc <= max_alloc AND SUM(alloc) <= 100
MAXIMIZE MIN(alloc / need);

Answered by direct solve (R4_MAX_MIN_FAIRNESS): DuckDB operators compute the optimum, no solver is called.

How it reads

  • alloc <= max_alloc
    A cap per program.
  • SUM(alloc) <= 100
    One shared budget.
  • MAXIMIZE MIN(alloc / need)
    Make the smallest share of need as large as possible.

The answer

Every program receives 83.3% of its need. Shelter's share is also its cap, 25 units. On the solver path this is a linear program with an auxiliary variable for the minimum; direct solve computes the level without one.
