Rebalance toward target weights

The targets add up to more than 100% and one asset has a cap. Find the allowed weights closest to the targets.

quadratic objectiveREAL decisionleast squares

The problem

An advisor's target allocation adds up to 110%, and the stock target exceeds its 50% cap. The closest valid allocation, in the least-squares sense, minimizes the sum of squared differences: a convex quadratic program, which both bundled HiGHS and Gurobi solve.

The data

Setup
CREATE TABLE Holdings (asset VARCHAR, target DOUBLE, max_weight DOUBLE);
INSERT INTO Holdings VALUES
    ('Stocks', 0.55, 0.50), ('Bonds', 0.30, 0.40),
    ('Gold', 0.10, 0.10), ('Cash', 0.15, 0.20);

The query

DECIDE query
SELECT asset, target, max_weight, ROUND(w, 4) AS w
FROM Holdings
DECIDE w(REAL)
SUCH THAT w <= max_weight AND SUM(w) = 1
MINIMIZE SUM(POWER(w - target, 2));

Problem class: QP.

How it reads

  • DECIDE w(REAL)
    A continuous weight per asset, 0 or more.
  • SUM(w) = 1
    Weights add up to 100%.
  • SUM(POWER(w - target, 2))
    The squared distance from the targets. POWER(e, 2), e ** 2 and e * e are the same square.

The answer

Stocks sit at their 50% cap. The remaining excess comes off the other three targets in equal amounts, about 1.67 percentage points each, which is what least squares does when no other bound is active.
