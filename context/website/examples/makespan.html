Balance work across machines

Assign each job to one of two machines so the busier machine finishes as early as possible.

ILP
decidb · makespan.sql
SELECT machine, job, hours FROM (
    SELECT M.machine, J.job, J.hours, run
    FROM Jobs J CROSS JOIN Machines M
    DECIDE run(BOOL)
    SUCH THAT per J: SUM(run) by (J) = 1
    MINIMIZE max(per M.machine: sum(run * J.hours) by (M.machine))
) WHERE run = 1
ORDER BY machine, job;

The problem

Six jobs, two machines. Every job runs once, on either machine. The goal is the classic makespan: make the load of the busiest machine as small as possible. The objective reads like the sentence: the max over machines of each machine's sum of hours.

The data

SetupRuns as shown
CREATE TABLE Jobs (job VARCHAR, hours INT);
INSERT INTO Jobs VALUES ('J1', 7), ('J2', 5), ('J3', 4), ('J4', 3), ('J5', 3), ('J6', 2);

CREATE TABLE Machines (machine VARCHAR);
INSERT INTO Machines VALUES ('M1'), ('M2');

The query

DECIDE queryRuns as shown

Problem class: ILP, solved by Gurobi or HiGHS.

How it reads

FROM Jobs J CROSS JOIN Machines M
Every job–machine pair is a row with its own decision.
per J: SUM(run) by (J) = 1
Each job runs on exactly one machine.
max(per M.machine: sum(...) by (M.machine))
The two-level objective: an inner sum per machine, then the max over those sums. MINIMIZE makes the busiest machine as light as possible.

The answer

The 24 hours split evenly: 12 hours per machine. M2 runs the two long jobs, M1 the four short ones.
