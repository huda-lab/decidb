Meet demand at the lowest cost

Decide how many units each plant makes, within its capacity, so that total output meets demand at the lowest cost.

ILP

The problem

Decisions are not only yes or no. An INT decision is a whole quantity, 0 or more. Four plants can make the same part at different costs; 500 parts are due.

The data

SetupRuns as shown
CREATE TABLE Plants (plant VARCHAR, capacity INT, unit_cost DOUBLE);
INSERT INTO Plants VALUES
    ('Austin', 300, 12.5), ('Boston', 200, 10.0),
    ('Chicago', 250, 11.0), ('Denver', 150, 9.5);

The query

DECIDE queryRuns as shown
SELECT plant, capacity, unit_cost, units
FROM Plants
DECIDE units(INT)
SUCH THAT units <= capacity
      AND SUM(units) >= 500
MINIMIZE SUM(units * unit_cost);
Result4 rows

Problem class: ILP, solved by Gurobi or HiGHS.

How it reads

DECIDE units(INT)
A whole number of units per plant, 0 or more by default.
units <= capacity
A constraint with no reducer holds on every row: each plant stays within its own capacity.
SUM(units) >= 500
Together the plants make at least 500 units.
MINIMIZE SUM(units * unit_cost)
Spend as little as possible.

The answer

The cheapest plants fill first: Denver and Boston run at capacity, Chicago makes the remaining 150, and Austin, the most expensive, makes nothing. Total cost: 5,075.
