Pack the most valuable bag

Choose which items to carry so their total weight stays under a limit and their total value is as high as possible.

ILP

The problem

A photographer can carry 50 kg of gear. Each item has a value to the shoot and a weight. Which items go in the bag? Each row is a yes-or-no choice, so the decision is a BOOL: one 0/1 value per row.

The data

SetupRuns as shown
CREATE TABLE Items (item VARCHAR, value INT, weight INT);
INSERT INTO Items VALUES
    ('Laptop', 100, 20), ('Camera', 60, 10), ('Drone', 120, 30),
    ('Tripod', 40, 15), ('Lens', 75, 12);

The query

DECIDE queryRuns as shown
SELECT item, value, weight, x AS take
FROM Items
DECIDE x(BOOL)
SUCH THAT SUM(x * weight) <= 50
MAXIMIZE SUM(x * value);
Result5 rows

Problem class: ILP, solved by Gurobi or HiGHS.

How it reads

DECIDE x(BOOL)
One decision per row of Items, 0 or 1.
SUM(x * weight) <= 50
The chosen items weigh at most 50 kg in total. SUM reads every row.
MAXIMIZE SUM(x * value)
Among all choices that fit, return the one with the highest total value.
x AS take
A decision is a column of the result like any other: select it, rename it, compute with it.

The answer

Laptop, camera and lens: 42 kg and a value of 235. The drone is worth more than any single item but costs 30 kg, and every set that includes it is worth less than 235. Every row comes back, with its decision filled in.
