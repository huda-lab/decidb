Getting Started with DecidB

Install DecidB and run your first optimization query.

On This Page

  • Prerequisites
  • Installation
  • Your First Query

1 Prerequisites

Requirements depend on your installation method:

Binary Downloads (Recommended)

No prerequisites. DecidB binaries are self-contained.

Building from Source

  • C++ Compiler: GCC 9+, Clang 10+, or MSVC 2019+
  • CMake: Version 3.15+
  • Python: Version 3.7+ (parser generation)
  • Git: For cloning the repository
  • Make or Ninja: Build system
  • Gurobi (optional): Auto-detected at build time. If installed, Gurobi is used as the primary solver; otherwise the bundled HiGHS solver is used.

Supported Platforms

  • Linux x86-64 (Ubuntu 18.04+)
  • macOS 11.0+ (Intel & Apple Silicon)
  • Windows 10+ (x64)
Development Status

DecidB is in active development. The master branch contains the working prototype.

2 Installation

Step 1: Choose Your Platform

Platform Requirements Filename
Linux x86-64 Ubuntu 18.04+, CentOS 7+ decidb_cli-linux-amd64.zip
macOS Universal macOS 11.0+ decidb_cli-osx-universal.zip
Windows x64 Windows 10+ decidb_cli-windows-amd64.zip

.gz archives are also available for Linux and macOS in the release assets.

Step 2: Download from GitHub Releases

Latest Release

Download the ZIP file for your platform from the Assets section.

Step 3: Extract and Verify

Linux / macOS

Bash 
# Extract the downloaded file (adjust filename for your platform)
unzip decidb_cli-linux-amd64.zip

# Make executable
chmod +x decidb

# Verify installation
./decidb --version

Windows (PowerShell)

PowerShell 
# Extract ZIP file using File Explorer or:
Expand-Archive decidb_cli-windows-amd64.zip -DestinationPath .

# Verify installation
.\decidb.exe --version
Unsigned Binaries

macOS: Right-click → Open → confirm.

Windows: SmartScreen → "More info" → "Run anyway".

Step 4: Test Installation

Bash 
# Test basic query
./decidb -c "SELECT 'DecidB is ready!' as message;"

Step 1: Clone the Repository

Bash 
git clone https://github.com/huda-lab/decidb.git
cd decidb

Step 2: Configure and Build

Linux / macOS

Bash 
make release

Windows (PowerShell)

Requires Visual Studio 2019+ and Ninja installed.

PowerShell 
cmake -G Ninja -B build/release -DCMAKE_BUILD_TYPE=Release -DDISABLE_UNITY=1
ninja -C build/release

Step 3: Verify Installation

Linux / macOS

Bash 
# Verify installation
./build/release/decidb --version

# Test basic query
./build/release/decidb -c "SELECT 'DecidB is ready!' as message;"

Windows (PowerShell)

PowerShell 
# Verify installation
.\build\release\decidb.exe --version

# Test basic query
.\build\release\decidb.exe -c "SELECT 'DecidB is ready!' as message;"

Bash 
pip install decidb

3 Your First Query

A classic knapsack problem: select items to maximize value within a weight limit.

Start DecidB

Bash 
# Start DecidB with a new database
./decidb my_database.db

This opens an interactive SQL shell. You can also use ./decidb without a filename for an in-memory database.

Create Sample Data

In the DecidB shell, run:

SQL 
CREATE TABLE Items (
    id INTEGER,
    value INTEGER,
    weight INTEGER,
    category VARCHAR
);

INSERT INTO Items VALUES
    (1, 100, 20, 'electronics'),
    (2, 60, 10, 'electronics'),
    (3, 120, 30, 'electronics'),
    (4, 50, 50, 'furniture');

Write the Optimization Query

SQL 
SELECT id, value, weight, x
FROM Items
WHERE category = 'electronics'
DECIDE x IS BOOLEAN
SUCH THAT
    SUM(x * weight) <= 50
MAXIMIZE SUM(x * value);

What Each Clause Does

  1. 1
    WHERE category = 'electronics' — Only electronics are considered. Item 4 (furniture) is excluded.
  2. 2
    DECIDE x IS BOOLEAN — Creates a binary (0/1) variable x for each remaining row.
  3. 3
    SUCH THAT SUM(x * weight) <= 50 — The total weight of selected items cannot exceed 50.
  4. 4
    MAXIMIZE SUM(x * value) — Pick the combination with the highest total value.

Expected Output

id value weight x
1 100 20 1
2 60 10 0
3 120 30 1

Result: Items 1 and 3 are selected (x = 1). Their combined weight is exactly 50 (at the limit) and their combined value is 220 — the highest achievable. Item 2 is skipped (x = 0) because including it would push the total weight to 60.

Alternative: Run from Command Line

You can also run queries directly from your terminal without entering the interactive shell:

Bash 
# Run a query file
./decidb my_database.db -f query.sql

# Or execute inline
./decidb my_database.db -c "SELECT * FROM Items;"
